# Eternal Vengeance

This is a small top down shooter game made for a game jam built in godot. This has been open-sourced as while there are plans for one more final update
the game is finished and due to a lack of popularity and time to give to the game the source code is released so people can:
make their own versions of the game, Borrow code from the game, or just learn from how the game was made
